# Проверка производительности

В `dataset/performance_cases.json` заданы два сценария: `filter_1000` (1000 элементов) и `rapid_filter_switch` (50 переключений фильтра).

## Как измерить

1. Запустить `npm run dev`.
2. Открыть Chrome/Chromium DevTools → Performance.
3. Для `filter_1000` подготовить массив из 1000 записей в консоли/тестовом окружении и выполнить фильтрацию через `filterItems`; записать длительность нескольких повторов.
4. Для `rapid_filter_switch` 50 раз менять поисковый запрос; записать общее время сценария и проверить, что список остаётся корректным.
5. Повторить измерение после изменения кода при одинаковых условиях.

## Архитектурное изменение

Производный список рассчитывается через `computed` в composable, а не хранится отдельной копией. Это устраняет ручную синхронизацию состояния. Функция фильтрации вынесена в чистую функцию, поэтому её можно отдельно тестировать.
