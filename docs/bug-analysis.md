# Анализ дефектов

| ID | Дефект из dataset | Исправление | Проверка |
|---|---|---|---|
| B01 | Повторная фильтрация прямо в шаблоне | `computed` в `useCatalog` | unit-тест `filterItems` |
| B02 | Мутация prop в дочернем компоненте | `defineEmits`, состояние меняет родитель | проверка структуры `ItemCard.vue` и ручное переключение |
| B03 | `v-for key` равен индексу | `:key="item.id"` | просмотр шаблона, ручное удаление/перестановка |
| B04 | Ошибка при отсутствующем поле | `normalizeItems` задаёт безопасное значение | unit-тесты null и отсутствующего title |

Негативные записи из `broken_items.json` отображаются с названием «Без названия». Исходные JSON-файлы сохранены в `dataset`.
