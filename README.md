# Практическая работа №14
## Vue. Оптимизация, принципы архитектуры и автоматизированная проверка корректности

### Описание
Учебное приложение для аудита набора записей. Оно использует файлы `dataset`, безопасно нормализует некорректные записи, выполняет поиск и фильтрацию, позволяет добавлять, удалять и менять статус записей.

### Технологии
- Vue 3 (`script setup`, Composition API)
- Vite
- Vitest
- ESLint

### Установка и запуск
Требуется Node.js и npm.

```bash
npm install
npm run dev
```

### Проверки
```bash
npm test
npm run lint
npm run build
```

### Используемые данные
- `dataset/bug_cases.json` — четыре типа дефектов, разобранных в работе.
- `dataset/broken_items.json` — исходные записи, включая отсутствующее и null-поле `title`.
- `dataset/performance_cases.json` — два сценария измерения.
- `dataset/quality_checklist.csv` — исходный чек-лист; рабочая копия находится в `docs/quality_checklist.csv`.

### Найденные проблемы и исправления
1. Повторная фильтрация в шаблоне — вычисление вынесено в `computed` внутри `useCatalog`.
2. Мутация `prop` — `ItemCard` не изменяет входной объект, а отправляет события `toggle` и `remove`.
3. Нестабильный индексный ключ — список использует `:key="item.id"`.
4. Отсутствующее поле — `normalizeItems` подставляет безопасное название «Без названия».

### Архитектура
- `App.vue` — собирает экран и связывает действия.
- `FilterPanel.vue` — отображает фильтры и сообщает об изменениях через события.
- `ItemCard.vue` — отображает отдельную запись и отправляет события.
- `useCatalog.js` — хранит состояние и вычисляет производные данные.
- `utils/items.js` — чистые функции нормализации, фильтрации и статистики.

### Автоматизированные проверки
В `tests/items.test.js` проверяются нормализация пропущенных значений, безопасная обработка некорректного источника, фильтрация и подсчёт статистики.

### Производительность
Порядок проведения замеров для `filter_1000` и `rapid_filter_switch` и таблица для фактических значений находятся в `docs/performance.md`. Измерения необходимо выполнить в браузере на целевом компьютере.
